# Jarvis 自我成长与知识整理规格

> 状态：需求访谈检查点。本文整理已经确认的长期个人理解、周期复盘、知识图谱和成长上下文边界；其中多项能力安排在第一版监督闭环稳定后实现。

## 1. 建设顺序

Jarvis 先建立个人成长档案，理解用户的目标、项目、偏好、边界、行为模式和有效帮助方式；个人模型稳定后，再扩展个人知识图谱。授权资料不进行一次性全量画像，而是在聊天、复盘和具体任务中渐进了解。

## 2. 个人成长档案

个人成长档案优先包含：

- 长期目标、当前项目和重视的事情；
- 用户明确表达的偏好、禁忌和陪伴边界；
- 监督与复盘中反复出现的行为模式；
- 对用户有效的提醒、鼓励和工作方法。

### 2.1 记忆可信程度

- 已确认信息：用户明确表达或亲自确认，可以稳定影响 Jarvis 的长期行为。
- 观察模式：由多次记录支持，附有证据和可信程度，只用于温和提问。
- 待确认推测：Jarvis 对原因或性格的暂时解释，确认前不能成为长期事实或自动决策依据。

系统不得因一次事件形成懒惰、自制力差等永久标签。

### 2.2 低打扰确认

- 用户明确说出的偏好或边界，轻量提示“已记住”并允许立即撤销。
- 观察模式集中在每日或周期复盘中确认，不在工作时打断。
- 待确认推测只能在相关对话中向用户提问。
- 记忆中心允许查看、搜索、修改、合并、否认和删除任何记忆。
- 每条记忆显示来源和形成时间。

### 2.3 记忆变化

- 新信息成为当前有效内容，旧信息标记为已替代并默认不再影响当前行为。
- 疑似属于场景差异时先询问适用范围，不直接覆盖。
- 临时情绪和短期状态具有有效期限，不自动成为永久性格。
- 用户可以删除单条旧记录或完整变化历史。

### 2.4 可见级别

- 普通：可以在相关私人对话中自然引用。
- 私密：只在用户已经打开对话面板后引用，不出现在桌面气泡、通知预览或自动语音中。
- 仅在询问时使用：只有用户主动问到时读取和引用。

健康、财务、关系、情绪和私人聊天默认建议标为私密。公开场合模式不展示敏感记忆。

## 3. 授权资料源

Jarvis 只读取用户明确授权的文件、文件夹或聊天项目。原始资料保持只读，不扫描其他位置。

### 3.1 安全排除

即使上级目录已经授权，也默认排除：

- `.env`、密钥、令牌、密码和凭据；
- `.git` 内部数据；
- 依赖目录、构建产物、缓存和临时文件；
- 可执行文件及无须理解的二进制文件；
- 明确标记为私密或禁止学习的目录。

被排除内容只有在具体任务中被用户明确指定时才临时读取，并且不自动进入个人成长档案。

### 3.2 优先资料源

- `D:\Desktop\codex\20260807闲聊`
- `D:\Desktop\codex\20260628辅助交易`
- `D:\Desktop\codex\20260806时间管理项目`
- `D:\Desktop\codex\20260621紫微斗数+AI`
- `D:\Desktop\codex\20260619口播`
- `D:\Desktop\紫微斗数`
- `D:\Desktop\风水`

其他 Codex 项目只在当前话题确实相关时按需读取。

### 3.3 相关性筛选

- 优先处理聊天、反思、日记、计划、目标、复盘、需求讨论和用户亲自写下的重要决策。
- 研究笔记、项目文档和设计方案只在当前话题相关时读取。
- 普通源代码、测试、配置样板、生成内容、第三方资料和美术资源默认不进入个人成长档案。
- 项目内容只有在反复体现用户习惯、技能方向或价值取舍时，才可以形成带来源的候选认识。

### 3.4 撤销来源

移除资料源时，用户选择保留已确认记忆，或连同派生记忆和知识一起删除。未确认候选默认删除；被保留内容标明原始来源当前不可用。

## 4. 可控进化

Jarvis 的进化表现为个人成长档案更准确、沟通方式更适配，以及使用行为实验验证更有效的服务方式。

- 行为实验必须经用户确认，具有明确期限，可随时撤销并记录效果。
- Jarvis 可以建议修改模板和监督参数。
- Jarvis 不能自行修改工作承诺、核心监督规则、系统提示词、程序或权限边界。
- 正式变化必须有版本记录。

## 5. 周期复盘

周期复盘默认每 14 天进行一次，由用户选择固定复盘日和时间；可以改为 7 天、28 天或自定义天数。修改只影响未来安排。错过后进入待补，不自动跳过或生成总结。

周期复盘包括：

- 计划与实际完成情况，分别呈现投入目标和成果目标；
- 相关活动、偏离、休息、推迟和未回应趋势；
- 有证据支持的有效做法和反复问题；
- 与上一周期相比的真实变化；
- 新观察模式和待确认推测；
- 行为实验效果；
- 下一周期最多一至三个周期重心或新实验。

不使用人格分数、自律值或制造焦虑的排行榜。每个判断都应能追溯到记录。

## 6. 个人知识图谱

个人知识图谱用于检索、连接和复习用户接触与思考的主题，不等同于个人成长档案。

### 6.1 主要用途

- 回答用户过去接触过什么主题、形成过什么观点；
- 将新内容连接到已有主题、项目、问题和笔记；
- 发现与当前周期重心相关且值得重新回顾的知识；
- 生成低负担的复习问题；
- 让结论追溯到文件、对话或记录。

可视化关系图只是辅助浏览方式。

### 6.2 观点来源

- 资料观点必须标明来源，不能表述为用户观点或普遍事实。
- 用户观点保留表达时间和适用上下文。
- AI 整理必须清楚标记，不能冒充资料原文或用户观点。
- 冲突资料可以共存并展示分歧。
- 当前用户观点优先，旧观点可以保留为思考变化历史。

### 6.3 简化的复习标记

知识图谱不维护已接触、能够解释、已经应用或精通等等级。资料被读取不代表用户已经学会；只保留来源和可选的“值得复习”标记。

### 6.4 周期重心与关键知识

- 周期复盘确定一至三个周期重心。
- Jarvis 据此提议本周期总计三至七条关键知识。
- 每条说明对应重心、推荐原因和原始来源。
- 用户可以确认、删除、替换或添加。
- 上一周期普通标记退出当前清单但保留历史。
- 特别重要的内容可以长期置顶。
- 周期中可以建议新增，但不能无限扩张清单。

### 6.5 每日知识候选

每日复盘结束时最多提出三条候选，只包括：

- 当天新理解或改变看法的概念；
- 项目实践中的重要结论、方法或教训；
- 新出现的关键问题及其与已有知识的联系。

普通软件使用、重复工作和琐碎待办不进入知识图谱。候选由用户接受、修改或忽略；没有高价值内容时可以为零。

## 7. 成长上下文

### 7.1 上下文模式

- 已授权 Codex 文件和聊天按需直接读取，不监听键盘。
- 其他软件的实时成长上下文默认关闭。
- 用户按应用或单次会话显式开启上下文模式。
- 开启期间持续显示状态，并提供一键暂停。
- 密码、支付、认证、隐私窗口和黑名单应用始终禁止采集。
- 优先使用软件接口、文档和窗口结构，截图只是后备方式。
- 成长上下文不能用于监督判定。

### 7.2 原始内容期限

- 原始截图、文字片段和点击信息优先只在内存中处理；确需跨进程或故障恢复时才进入当前 Windows 用户的临时缓存。
- 会话结束时可以删除，最长保留 48 小时。
- 只有用户确认的提炼结果长期保存。
- 用户可以主动保留指定原文及来源、时间和范围。
- 授权文件继续以原文件为来源，不额外复制永久快照。
- 不建立长期键盘日志、连续截图档案或可回放屏幕历史。
- 删除原始内容后，用户可以查看并一并删除由其产生的提炼结果。

## 8. 云端 AI

- AI 是闲聊、自然语言理解、复盘辅助、记忆提炼和知识整理的增强层，不是工作承诺、监督状态机、计时、提醒升级或正式记录的权威来源。
- 断网、模型超时、服务故障、额度耗尽或用户关闭 AI 时，成长与知识功能可以明确暂停或降级，但不能影响确定性监督核心，不能丢失既有记录，也不能伪造提炼、总结或回复。
- AI 恢复后可以继续处理用户重新提交或明确保留的内容，但不得追溯改写故障期间已经形成的监督事实。
- 第一版默认使用云端模型 API；本地模型作为后续增强，用于仅限本机资料、离线对话或降低云端依赖，不作为第一版交付前提。
- 云端模型通过模型供应商适配器接入。用户必须能看见并配置当前服务商；更换服务商不能改变记忆格式、资料授权或确定性监督核心，也不能在故障时无感转发私人内容。
- 第一版先试运行 DeepSeek：普通闲聊、承诺回顾和记忆候选使用 `deepseek-v4-flash` 非思考模式；两周复盘、复杂原因归纳和跨资料知识综合才按模型路由使用 `deepseek-v4-pro` 思考模式。
- `qwen3.7-flash` 只参与脱敏同题 A/B，不作为无感故障备援。试运行两周后结合用户盲评、结构化可靠性、延迟、失败率、隐私设置和实际费用确认正式默认。
- 首次配置 DeepSeek 时引导并确认退出输入训练/优化用途；无法确认时不得声称不会用于训练。模型和隐私条款变化时重新提示，既有资料授权不能因供应商变化自动扩大。
- 所有云端供应商合并执行每个本地自然月 30 元的默认费用硬上限；15 元和 24 元提醒，预计单次超过 1 元先确认。达到上限后停止新的云端提炼、复盘和知识任务，不自动充值，也不允许后台任务或切换供应商绕过。
- 每次请求记录供应商、模型、用途、token、当时价格版本和计算费用，但不为费用审计复制完整私人提示词；价格或计费字段不确定时保守暂停并请求用户确认。
- 用户为每个云端供应商提供自己的独立 API Key；Jarvis 不内置共享密钥或通过项目自建服务器中转。凭据只保存在当前 Windows 用户和当前电脑的凭据管理器中，仅 Core 可在调用时读取完整值。
- 供应商凭据不属于个人成长档案或可迁移数据，不进入数据库、日志、崩溃报告、导出、密码保护备份或百度网盘；换电脑和恢复备份后重新输入。删除配置时删除本机副本并提示去供应商后台撤销。
- 默认卸载保留本机成长档案、知识数据、密码保护备份和本机凭据以便重新安装恢复；选择彻底删除时二次确认并清理本机正式数据、记录、备份与凭据，但不删除百度网盘云端副本或用户在本机之外记录的备份密码。
- 只发送完成当前问题所需的少量相关片段，不上传整个文件夹或完整历史。
- 明确显示本地或云端模型及云端服务商。
- 每个资料源可以选择允许云端处理或仅限本机。
- 私密和仅在询问时使用的记忆默认需要额外允许云端处理。
- 保留可查看的云端请求记录。
- 本地能力不足时明确说明功能不可用，不得静默切换云端。

## 9. 本地数据保护

- 个人成长档案、知识图谱、复盘和长期确认内容所在的本机正式数据库不做 Jarvis 应用层加密，放在当前 Windows 用户的应用数据目录；建议用户启用 Windows 设备加密或 BitLocker。
- 该边界不防止能够读取当前 Windows 用户文件的人直接阅读数据库。成长上下文真正进入实现前必须再次检查原始截图和输入文字是否需要长期落盘；若需要，重新评估应用层数据库加密，不能把当前简化决定自动扩展到新的高敏感数据。
- 原始资料仍以原文件自身的权限和保护方式为准；授权读取不会自动复制或替原文件加密。
- 只有离开当前电脑的百度网盘备份、手动导出和迁移包使用一个备份密码进行密码保护。该密码可以保存在当前电脑的 Windows 凭据管理器中用于自动备份，新电脑恢复时由用户输入；不另设数据库密钥或恢复密钥。
- 忘记备份密码但本机数据库仍在时，可以设置新密码重新生成备份；本机数据和密码同时丢失时，旧密码保护备份无法恢复。更换密码后旧备份仍需要原密码。
- 核心每天自动创建一次密码保护备份，并在程序升级或数据库迁移前额外创建一次；用户可以随时手动触发。备份从一致的数据库快照生成并自动校验完整性和版本，失败时明确告警，不能把未验证文件显示为成功。
- 第一版将密码保护备份写入由百度网盘 Windows 客户端负责上传的本地目录，不直接接入百度 API 或保存百度凭据；本地备份成功不能表述为云端上传成功，客户端未运行时标记为等待上传。
- 本地默认保留 30 份每日、12 份月度和 3 份升级或迁移前备份；只有新备份校验成功后才清理超期本地文件。第一版不自动删除百度网盘云端旧文件，只提示用户检查空间。
- 新备份生成后 24 小时未检测到百度网盘客户端运行，只在桌宠和托盘提醒，之后每天最多一次，不进入飞书。客户端运行不等于云端上传成功，界面持续区分本地成功与云端状态未知。
- 设置中提供用户主动触发的隔离“测试备份”和“恢复备份”，但第一版不要求首次或每六个月强制恢复演练。

## 10. 明确不做

- 一次性全量读取所有项目并固化用户画像。
- 通过单次事件形成永久性格标签。
- 复杂知识掌握等级、精通度、题海、分数或连续打卡。
- 将成长上下文用于监督判定。
- 长期键盘日志、连续截图或屏幕回放档案。
- 未经确认的自主程序、提示词、权限或监督规则改写。
