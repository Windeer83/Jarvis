# 第一版暂定采用 .NET 10 与 WPF

Jarvis 第一版暂定使用 `.NET 10 LTS + C# + WPF` 实现 `Jarvis Core` 和 `Jarvis Desktop`，让后台监督、Windows 系统能力、命名管道、托盘和桌面界面保持在同一技术体系中；聊天、设置与复盘优先使用原生 WPF，只有知识图谱等确有需要的复杂页面才按需创建 WebView2。这一选择牺牲 Web 优先框架的界面开发速度和跨平台复用，换取更直接的 Windows 集成、更简单的两进程边界，以及更有希望满足常驻资源预算的实现路径。该决定是待验证而非永久绑定：全面开发前必须用目标机原型验证透明桌宠、动画、穿透、进程恢复、WebView2 释放、安装升级和资源指标；若简化动画后仍不能达到基线，则制作 Tauri 2 同场景对照原型并重新决策。
