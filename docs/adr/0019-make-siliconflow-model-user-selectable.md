# 由用户选择硅基流动全局模型，默认 Flash

Jarvis 的硅基流动模型改为用户可见、可持久化的全局选择：默认所有云端 AI 请求都使用 `deepseek-ai/DeepSeek-V4-Flash` 并关闭思考模式；用户可以在 Desktop 明确切换为 `deepseek-ai/DeepSeek-V4-Pro`，切换后普通对话、自然语言候选、每日复盘和周期复盘统一使用所选模型。模型不会根据请求内容自行升级，也不会在失败时自动切换。

这一决定取代 ADR 0018 中“普通对话固定 Flash、复盘和复杂候选固定 Pro”的用途分层。当前试用阶段更需要让用户以低成本的 Flash 覆盖真实表达，再根据观察到的具体质量差异主动切换 Pro。选项保存在本机 SQLite 的非敏感设置中；API Key 仍只保存在 Windows 凭据管理器。每次请求仍按实际模型价格记录并受同一月度硬上限约束。
