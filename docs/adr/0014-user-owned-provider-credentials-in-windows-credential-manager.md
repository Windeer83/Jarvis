# 供应商凭据由用户持有并保存在本机凭据管理器

Jarvis 第一版不内置共享的模型 API Key，也不经项目自建服务器代转请求；用户自行在 DeepSeek、Qwen 等供应商创建、充值和撤销凭据，每个供应商独立配置。凭据通过 Windows 凭据管理器以当前用户、当前电脑的持久化范围保存，只有 `Jarvis Core` 在调用时读取完整值，Desktop 只显示供应商、状态和末四位。这个选择要求用户首次设置及换电脑后自行输入密钥，换取账号、费用和撤销权完全由用户控制，并避免 Jarvis 运营共享密钥或秘密中转服务。凭据不进入 SQLite、日志、崩溃报告、导出、备份密码、密码保护备份或百度网盘；删除本机配置后仍提示用户去供应商后台撤销，密钥故障只使 AI 降级而不影响确定性监督核心。
