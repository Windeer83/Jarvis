# ADR-0020：一电脑一手机使用证书指纹固定的局域网 HTTPS 同步

Jarvis V2-A 采用“一台 Windows Core 对一部私人手机”的局域网 HTTPS 同步。Windows Core 是工作承诺和手机策略的唯一权威；手机主动轮询、缓存当前已确认策略并在离线时执行到原定结束时间。首次配对由 Desktop 展示十分钟有效的一次性二维码，手机固定 Core 自签名证书的 SHA-256 指纹并交换随机设备令牌；令牌仅在手机 Android Keystore 与 Core 的不可逆哈希中保存。撤销配对后旧令牌立即失效。

此处的模块边界是 `MobileSyncModule`。它只暴露生成配对、配对、同步、状态投影和撤销五项操作；SQLite 与 HTTPS 是内部 Adapter。跨接缝协议带版本号，手机事件使用 UUID 幂等写入，同一承诺的旧策略版本不能覆盖新版本。同步异常、权限缺失和离线均投影为明确状态，不中断 Windows 核心监督。

本阶段不引入账号、云后端、mDNS、消息总线、多手机、远程推送或通用 Android 兼容层。普通 APK 的覆盖阻断属于目标华为手机上已验证的尽力而为机制，不能描述为系统级禁用或不可绕过。
