# 卸载默认保留本机数据并提供显式彻底删除

Jarvis 卸载默认只移除程序文件和自启动入口，保留本机数据库、本地密码保护备份、设置及当前电脑的供应商凭据，以便重新安装继续使用；用户可以通过需要二次确认的“同时删除本机数据”清理正式数据库、Jarvis 专用本地备份、设置、请求与费用记录、日志、崩溃报告和 Windows 凭据。删除前提供将最终密码保护备份保存到清理范围之外并验证的入口。这个选择可能在普通卸载后继续占用磁盘并留下私人数据，换取误卸载可恢复；彻底删除的范围必须明确且经过路径验证。卸载程序不调用百度网盘 API，不删除或声称删除云端备份，也不查找用户在本机之外记录的备份密码；正在监督时必须先取得停止监督确认。
