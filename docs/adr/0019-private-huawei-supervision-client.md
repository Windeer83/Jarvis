# 第二版使用华为专用手机监督端替代飞书

Jarvis 第二版不再并行维护飞书监督渠道，而是为用户当前的 HUAWEI Mate 70 Pro+（HarmonyOS 4.3.0）提供私人手动安装的手机监督端，在已确认工作承诺期间尽力阻断指定应用、接收提醒和记录临时开放；Windows Core 仍是正式业务权威，电脑与手机通过局域网配对，手机只缓存已确认策略并可离线执行到原定结束时间，不建设项目云端后端或通用移动产品。这个选择牺牲公开分发、异地即时同步和多机型兼容，换取直接处理用户主要的手机分心问题、更少的云端私人数据和较小的单用户范围；普通应用没有系统级暂停其他包的官方权限，前台识别、覆盖阻断与后台存活必须先通过目标真机原型，不能声称不可绕过，也不能以普通通知模拟阻断能力。
