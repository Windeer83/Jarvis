# 第一版只对便携数据使用备份密码

Jarvis 第一版不对运行中的本机 SQLite、WAL、临时文件或本地升级回滚副本增加应用层数据库加密，而是把它们放在当前 Windows 用户的应用数据目录中，并建议用户启用 Windows 设备加密或 BitLocker。只有会离开当前电脑的百度网盘备份、手动导出和迁移包使用一个用户设置的备份密码，通过成熟标准格式进行密码保护；该密码可以保存在 Windows 凭据管理器中支持自动备份，新电脑恢复时由用户重新输入。供应商 API Key 和飞书 Secret 继续作为独立凭据保存在 Windows 凭据管理器中，不进入正式数据库或密码保护备份。

这个选择不防止能够读取当前 Windows 用户文件的人直接查看本机数据库，换取删除 SQLCipher、自建原生加密组件、数据库密钥、独立恢复密钥、密钥轮换、多层 envelope 和专用数据库加密迁移。忘记备份密码时，只要本机数据库仍在，用户可以设置新密码重新生成备份；本机数据和密码同时丢失时，旧备份无法恢复。等产品确实需要长期落盘保存截图、输入文字等更敏感内容，或用户明确需要防止本机数据库文件被复制读取时，再重新评估应用层数据库加密。

本决定取代 ADR 0008。
