# 本机正式数据库默认加密

> 状态：已被 ADR 0017 取代。本文只保留原决定的历史，不再作为第一版实现依据。

Jarvis 默认静态加密包含监督、复盘、个人成长档案和知识内容的本机正式数据库，并使用受当前 Windows 用户账户保护的密钥自动解锁，不要求日常重复输入密码。这一选择增加加密组件、迁移和恢复设计成本，换取数据库文件被单独复制后不能直接读取；它不承诺防御已经登录该账户的人、运行中的本机访问或恶意软件。首次设置另行生成由用户独立保管的恢复密钥，用于每天自动生成、升级前生成和手动触发的加密备份以及新安装恢复；Jarvis 不将恢复密钥与备份同存，也不保留绕过密钥的恢复后门。首次设置和此后每 6 个月通过隔离恢复演练验证密钥与备份确实可用，不以文件存在或完整性校验替代实际恢复。
