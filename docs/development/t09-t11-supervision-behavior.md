# T09–T11 确定性监督、活动分类与限时休息

## 已交付

- Core 以相关、分心、未确定三态解释电脑活动。规则按单次承诺、承诺模板、全局默认的顺序选择；已确认承诺冻结自己的规则与休息设置。
- 交互型承诺把键鼠空闲计入偏离；被动型承诺在相关软件或网站保持前台时允许无输入。生产活动适配器只读取空闲时长、前台进程和支持浏览器的 hostname，不读取窗口标题、路径、查询、正文或输入内容；锁屏与任何不确定状态均按无法观察处理。
- 偏离在分心、交互型空闲和未确定之间连续累计；稳定相关两分钟才恢复。“马上回去”只记录意图，不清零。准备缓冲只抑制首次本机呈现，不推迟偏离起点。
- 明确分心累计五分钟后形成一次本机轻提醒、约十秒气泡与持续标记；同一段偏离不会重复发声。未确定五分钟后以中立问题询问，用户可以明确保存为相关或分心并选择作用范围。
- 交互型连续空闲十分钟后询问是否休息；确认后从空闲起点计算默认十五分钟总休息，到期自动恢复。否认或不回应继续偏离；主动休息必须给出结束时间。
- SQLite 是正式状态。提醒事实与运行状态、分类规则与纠正记录分别在具体事务中原子提交；本机呈现失败不会制造重复提醒。重启后的无法观察区间不计入偏离，也不补播过期声音。
- Desktop 配置窗口的关闭按钮仅隐藏窗口。提醒由同进程、不激活且不抢焦点的屏幕边缘小浮层呈现；点击浮层恢复完整面板。安静/会议/演示模式完全隐藏呈现；自动检测全屏时，只允许已明确分心的本机偏离提醒以无声气泡短暂显示。

本纵切不实现飞书提醒升级、承诺修订、角色动画、通用通知框架或新的常驻进程。

## 剩余人工观察

- 在目标电脑上确认 Chrome/Edge/Firefox 的地址栏 hostname 探针；地址栏聚焦、内部页和搜索词必须保持未确定。
- 触发一次真实全屏分心场景，确认浮层无声、不抢焦点且避开输入区域；安静/会议/演示模式下应完全隐藏。
- 试听一次低音量短音，并确认持续偏离不重播、解除静音不补播、恢复后新的偏离可以再次播放。
