# T23 有边界的陪伴表达与主动问候

## 交付边界

T23 只改变 Jarvis 的表达与低频主动问候，不改变 Core 的事实、监督判断和正式记录：

- 用户可以在同一控制面板切换专业表达或温和陪伴表达，并设置允许称呼、禁用称呼、不喜欢的语气和互动边界。
- 工作承诺进行中始终采用简短、坚定的监督表达；复盘采用更温和的教练式表达；普通对话在用户允许时才使用称呼。
- 云端对话只收到这些表达边界，不会因此获得修改监督规则、数据库或正式承诺的权限。
- 主动问候只在 10:00–22:00、没有进行中承诺且活动可观察时生成。最初每天最多一次；已有多次回应且回应多于忽略后才允许每天第二次。
- 连续忽略会把下一次问候分别推迟至少 2 天或 4 天；单次明确忽略会立即结束，不追问、不表示失望。
- 全屏、指定隐藏软件或桌宠不可见时，问候保持为“尚未呈现”，不会开始两小时窗口，也不会计为忽略。Desktop 确认桌宠真实显示后，Core 才记录本次呈现并开始到期计时。
- 没有亲密度、心情、饥饿、投喂、金币、商店、陪伴任务或照顾义务；不使用生气、吃醋、冷落、羞辱、愧疚或感情承诺影响用户。

## 权威边界

陪伴设置、当前问候、回应次数、忽略次数和降频水位保存在 Core 已有 SQLite 设置中。桌宠只投影 `CompanionSnapshot`，不会自行生成问候或修改统计。问候回应只保存本次问候文本与用户回应；未回应不会生成虚构聊天记录。

## 自动验证

```powershell
& ..\..\Jarvis\.tools\dotnet\dotnet.exe build Jarvis.slnx -c Release
& ..\..\Jarvis\.tools\dotnet\dotnet.exe test Jarvis.slnx -c Release
& ..\..\Jarvis\.tools\dotnet\dotnet.exe format Jarvis.slnx --verify-no-changes
& ..\..\Jarvis\.tools\dotnet\dotnet.exe list Jarvis.slnx package --vulnerable --include-transitive
```

`CompanionPersonaScenarios` 覆盖设置重启、AI 表达边界、工作/睡眠抑制、回应记录、明确忽略降频，以及“隐藏问候不算忽略、实际呈现后才开始到期”。`CompanionPersonaPresentationScenarios` 覆盖桌面表单映射和问候投影。

## 人工验收保留项

- 观察专业表达与温和陪伴表达是否符合个人偏好，禁用称呼是否从实际对话中消失。
- 在普通桌面看到一次主动问候，确认点击可打开回应区；明确忽略后不再追问。
- 在全屏或指定隐藏软件中确认桌宠不出现；退出抑制场景后才开始本次问候的呈现窗口。
- 在监督进行中确认不会出现闲聊式主动问候，监督事实和计时不受表达设置影响。
