# T21–T28 统一人工验收手册

本手册是 T21–T28 的目标机人工验收入口。自动化已经覆盖事务、重启、迁移、并发、失败回滚和数据边界；这里仅验证真实 Windows 桌面、麦克风、模型、文件系统与安装体验。

## 开始前

1. 使用可丢弃的测试承诺和测试数据，不要把安全清除用于唯一的正式数据。
2. 先完成 T21–T27；T28 的安全清除永远放在最后。
3. 为 T26/T28 准备两个不同目录：一个模拟百度网盘客户端同步目录，一个用于范围外最终备份。
4. 每项保留一张关键截图；若失败，记录页面、输入、时间和窗口底部错误，不要粘贴 API Key 或备份密码。

## 推荐顺序

### 1. T21 AI 辅助复盘

位置：**手机闭环、复盘与 AI（T15–T21） → AI 复盘辅助（T21）**。

1. 先完成一次每日复盘，留下至少一条回答；选择“整理当前每日复盘”。
2. 确认生成期间显示“正在生成”与进度，生成/确认按钮不能被重复点击。
3. 核对最小事实范围，编辑 AI 草稿，填写 1–5 分及四项边界评价，再确认写入。
4. 再做一次周期复盘；如测试 Qwen，只手工复制脱敏提示，不让 Jarvis 自动向第二家模型发送。

通过指标：原复盘始终可用；AI 只生成草稿，确认前不形成正式记录；失败时有明确降级；确认历史保存模型、延迟、费用、是否编辑和边界评价；完整提示词、密钥和无关历史不出现。

### 2. T22 桌面形象

位置：桌面形象本体、右键菜单、Core 托盘。

1. 依次观察空闲、工作、提醒、开心、关怀，以及休息/对话/休眠标记。
2. 在主屏和第二屏拖动，检查边缘吸附；切换尺寸并重启，位置和大小应恢复。
3. 开启自动移动，确认只在空闲小范围移动且不跨屏。
4. 开启鼠标穿透，再按 `Ctrl+Alt+J` 恢复；隐藏后从 Core 托盘重新打开。
5. 在全屏、PowerPoint 或指定软件中确认桌宠隐藏，但监督继续。

通过指标：不抢焦点、不越出工作区；状态与 Core 一致；关闭控制面板不停止监督；完全退出必须有明确确认。

### 3. T23 陪伴表达与主动问候

位置：同一控制面板的陪伴/表达设置和桌宠问候。

1. 分别测试专业表达和温和陪伴表达；配置允许称呼、禁用称呼和不喜欢的语气。
2. 在 10:00–22:00、无进行中承诺且活动可观察时等待一次主动问候；点击回应区，再明确忽略一次。
3. 在监督中、全屏或指定隐藏软件中确认问候不出现；退出抑制场景后才开始本次呈现窗口。

通过指标：禁用称呼不再出现；工作监督保持简短坚定；忽略后不追问、不表达失望；没有亲密度、投喂、金币或照顾义务。

### 4. T24 用户主动语音

位置：语音输入区域和四个目标选项。

1. 点“开始说话”，说一句中文，点“结束录音”；先编辑转写，再点“确认转写并继续”。
2. 分别选择普通对话、自然语言候选、承诺回顾、每日复盘。后两项还必须点击各自原提交按钮。
3. 普通对话检查文字先出现，再测试朗读、停止朗读、全局静音、30 分钟静音和仅耳机。
4. 拒绝麦克风权限或在无普通话识别组件环境测试一次，确认文字入口仍可用。

通过指标：不点击时绝不监听；单次最长 60 秒；未确认转写前不提交；不会把音频写入文件/数据库；专业、安静、会议、演示或全屏时不外放私人内容。

### 5. T25 数据保留、查询、导出与删除

位置：**数据保留与导出（T25）**。

1. 选择一个有监督事实的日期，核对详细时间线、归档汇总和承诺/回顾摘要。
2. 输入至少 12 字符密码导出；成功后密码框应清空。用错误密码验证拒绝，再用正确密码读取。
3. 只选可丢弃历史日期：先输错永久删除短语，再输完整短语；分别核对三种删除范围。

通过指标：导出不含密钥、聊天、截图、按键或文件正文；删除只影响所选日期/范围；承诺、版本、完成结果和复盘不会因详细时间线到期而消失。

### 6. T26 备份与恢复

位置：**备份与恢复（T26）**。

1. 选择百度网盘客户端同步的专用本地子目录，设置至少 12 字符密码，并可保存到 Windows 凭据管理器。
2. “立即生成并校验”，确认 `.jarvis-backup` 存在；界面只能说本地校验成功、云端状态未知。
3. 对同一文件先用错密码做隔离测试恢复，再用正确密码；当前正式数据不得变化。
4. 用可丢弃数据执行正式恢复：排队后完全退出并重开，核对数据回到备份状态并存在 `restore-rollback.db`。

通过指标：备份只有 `manifest.json` 与 `jarvis.sqlite3`；错误/损坏/不兼容文件不能排队；恢复不带入飞书或模型凭据；30/12/3 保留策略可读。

### 7. T27 安装、登录启动与普通卸载

位置：MSI 安装向导、Core 托盘、**安装与启动（T27）**。

1. 双击 MSI，核对首次说明和默认勾选的登录启动；取消再返回，确认可修改。
2. 安装后应先有 Core 托盘，再有 Desktop；关闭 Desktop 窗口只隐藏，不停止 Core。
3. 分别从托盘和 Desktop 关闭/开启登录启动，状态应同步。
4. 准备可丢弃哨兵数据后普通卸载，再重新安装。

通过指标：目标机无需预装 .NET 10；安装不要求管理员、不装服务、不开放端口；普通卸载删除程序与登录启动，但保留数据库、设置、备份和 Jarvis 凭据。

### 8. T28 手动更新、失败回滚与安全清除

位置：**更新与安全清除（T28）**。安全清除必须最后执行。

1. 保留一条正在监督的测试承诺，选择新版 MSI，不勾“停止当前监督”；更新应被阻止，监督继续。
2. 监督结束后重新预览，核对 MSI 摘要、升级备份、数据库回滚快照和二次确认短语；确认后观察退出、安装、真实 Core↔Desktop 健康检查与重启。
3. 核对承诺、设置、复盘和备份仍可读；维护状态只含状态、退出码和恢复目录，不含正文、密钥或密码。
4. 只在可丢弃 Windows 用户中测试安全清除：备份目录放一个无关文件，最终备份选择范围外另一目录；错误短语必须拒绝。
5. 输入完整短语后等待退出和清除；最后检查本机 Jarvis 数据、维护日志、Jarvis 命名备份、登录启动和三项 Jarvis 凭据消失。

通过指标：预览时能看到已验证备份的真实路径，确认安全清除时还会再生成并验证一份更新的最终备份；无关文件和范围外最终备份保留；不调用百度 API、不删除云端文件或 Jarvis 之外的密码。若升级失败，状态必须是 `rolled_back` 或明确的 `rollback_incomplete`，绝不能显示成功。
