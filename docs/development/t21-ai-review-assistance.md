# T21 AI 辅助复盘与模型试运行

## 交付边界

T21 在既有每日复盘和周期复盘之上增加一个可选的 AI 整理步骤：

- 每日复盘只发送当前复盘日期的事实摘要、原始回答和同日承诺回顾。
- 周期复盘只发送当前周期已生成的可追溯趋势投影。
- 不发送完整监督数据库、聊天历史、凭据或其他会话内容；内部 source ID 也不进入模型提示。
- 模型输出首先是可编辑的待确认草稿。确认前不会形成正式 AI 复盘记录，也不会修改承诺或监督状态。
- AI 不可用、凭据缺失、预算不足或结构化输出失败时，原有确定性每日/周期复盘继续可用。
- 全局模型选择沿用 T19 的明确选项；Jarvis 不会因“复盘较复杂”自行把 Flash 升级到 Pro。

正式记录保存原始模型草稿、用户最终确认文本、是否被修改、模型/供应商、最小事实范围说明，以及质量、结构可靠性、歧义处理、越权推断和隐私范围评价。完整提示词和 API Key 不进入 SQLite。

## 两周试运行证据

第一次每日或周期 AI 复盘请求会开启一个本机 14 天试运行窗口。Desktop 的
**“手机闭环、复盘与 AI（T15–T21） → AI 复盘辅助（T21）”** 展示：

- 请求总数、成功/失败数、每日/周期分项；
- 已确认草稿数、用户修改数；
- 平均响应延迟、累计费用、实际使用模型；
- 平均中文质量，以及结构可靠、歧义处理、无越权和最小事实范围的通过率；
- 两周窗口仍在进行或已经完成。

Qwen 对照只支持用户主动复制界面提供的脱敏提示、在外部手动运行 `qwen3.7-flash`，再把结果和评价粘贴回来。Jarvis 不会自动调用 Qwen、自动故障转移或向第二家供应商发送同一份资料。记录对照前必须明确确认提示的隐私范围。

## 用户路径

1. 先在“每日复盘”或“周期复盘”开始一场复盘，并留下至少一条真实回答/趋势。
2. 打开“AI 复盘辅助（T21）”，选择整理当前每日或周期复盘。
3. 生成期间界面显示进度条和“正在生成”，并禁止重复生成或确认。
4. 核对界面列出的最小事实范围，编辑草稿，填写 1–5 分质量评价及四项边界检查。
5. 点击“确认并写入正式复盘”。只有此时该草稿进入已确认历史。
6. 如需模型对照，人工检查脱敏提示后交给 Qwen，再粘贴结果并记录；此操作不会产生第二次 Jarvis 云端请求。

`CompanionDesktopPresentationScenarios` 和 `SqliteMigrationScenarios`：最小事实投影、真实 SiliconFlow JSON 边界、先草稿后确认、失败降级、手动 Qwen 不调用云端、14 天完成标志、UI 忙碌反馈、命令序列化，以及 v6→v7 原子迁移/失败回滚。

## 明确后置

- 两周真实使用样本由后续人工验收逐日累积；自动化只证明窗口、指标和持久化不会依赖等待或进程存活。
- T22 以后才引入长期个人成长档案、授权资料、语音、知识图谱和备份同步。
- T21 不让 AI 自动修改正式承诺、监督规则、每日/周期重点或长期记忆。
