# 手机配合步骤（Mate 70 Pro+ / HarmonyOS 4.3）

只按当前阶段操作；不需要提供序列号、IMEI，也不要开启 root、解锁 bootloader 或恢复出厂设置。

## A. 连接前

1. 暂时不要升级到 HarmonyOS 5 / NEXT。
2. 在“设置 → 关于手机”连续点击版本号，直到提示已经进入开发者模式。
3. 在“设置 → 系统和更新 → 开发人员选项”打开 USB 调试。
4. 用可传输数据的 USB 线连接电脑；如果出现 USB 用途，选择文件传输。
5. 手机上出现“允许 USB 调试”时，核对这是自己的电脑后允许。

## B. APK 首装与升级后

打开“Jarvis 手机阻断探针”，从上到下处理状态面板：

1. 允许“使用情况访问”。
2. 允许“显示在其他应用上层/悬浮窗”。
3. 允许通知，并保持探针通知可见。
4. 允许“闹钟和提醒/精确定时”特殊访问。
5. 在电池或应用启动管理中找到 Jarvis 探针，关闭自动管理，并允许自启动、关联启动和后台活动。不同 HarmonyOS 补丁的菜单名称可能略有不同，可在设置里搜索“应用启动管理”。
6. 暂时不要打开无障碍对照；先测首选的使用情况访问路径。只有首轮数据收集完成后，才打开“Jarvis 探针（仅测量窗口包名）”做对照。

所有权限都可以随时撤销。撤销权限、强制停止探针或卸载 APK 会绕过普通应用的尽力型阻断，这不属于系统级锁定能力。

## C. 人工阻断矩阵

自动100次桌面启动完成后，分别对抖音、B站、小红书和微信测试：

- 点击一条真实通知进入；
- 点击浏览器或聊天中的该应用深链进入；
- 从最近任务卡片恢复；
- 从桌面图标进入。

每种可用入口重复25次。只判断阻断页是否在能够滑动内容、播放视频或操作聊天之前出现，不向测试记录复制通知或聊天正文。

## D. 生命周期矩阵

使用30分钟策略逐项测试 Wi-Fi 关闭、Windows 端停止、息屏、从最近任务清除、低电量/省电模式和重启。策略到原定时间后应在10秒内解除；若权限或服务失效，结果必须记录为“监督不可用”，不能记成用户分心。

最后进行一次八小时运行，记录后台被杀次数、漏报和开始/结束电量。没有预设虚构的耗电门槛，先取得真机事实再决策。
