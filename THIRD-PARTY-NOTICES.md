# Third-party notices

Jarvis uses the following directly adopted open-source components in the V2 pre-install skeleton:

- [QRCoder](https://github.com/codebude/QRCoder), version 1.8.0, MIT License — generates the one-time pairing QR image in Jarvis Desktop.
- [ZXing Android Embedded](https://github.com/journeyapps/zxing-android-embedded), version 4.3.0, Apache License 2.0 — scans the pairing QR image in Jarvis Mobile. It includes ZXing Core under the Apache License 2.0.

Package binaries preserve their own embedded notices. This file records direct adoption; it does not change the licenses of Jarvis source code or other dependencies already distributed by the Windows installer.
